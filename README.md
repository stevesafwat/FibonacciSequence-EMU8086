# FibonacciSequence-EMU8086

🧮 Fibonacci Series Generator in x86 Assembly
This project is a console-based Fibonacci series generator written in x86 Assembly (MASM/TASM syntax) for DOS. It prompts the user to enter a number of terms (between 1 and 25) and prints the corresponding Fibonacci sequence, displaying each number on a new line. It also includes input validation and a rounding mechanism for decimal inputs.

📌 Features
-Prompts user for a number between 1 and 25

-Validates input and handles invalid or out-of-range entries

-Supports basic rounding of decimal inputs (e.g., 4.6 rounds to 5)

-Calculates Fibonacci numbers using an iterative approach

-Uses custom routines to:

-Read numeric input from the user

-Convert numbers to ASCII

-Print numbers character-by-character




🛠 Technologies Used
-x86 Assembly Language

-TASM/MASM-compatible syntax

-MS-DOS Interrupts (INT 21h) for input/output






🔍 What You Can Learn
-Low-level I/O using DOS interrupts

-Number parsing and conversion in Assembly

-Basic algorithm implementation in Assembly

-Working with registers, stack, and memory
